# 求人リスト（コーダー募集130社）差別化リサーチ

> 別リサーチ: 営業管理シートでランクVIP/A/B/Cが付いている26社の深掘り調査は
> **[`research/RANKED_ACCOUNTS.md`](./RANKED_ACCOUNTS.md)** を参照。
> 採用ページ・直近の制作実績・SNSの3軸調査に、コーディングでの打ち手と工数・金額を付けている。

## 成果物
- `data/harowaka_coder_jobs_base.csv` … 元スプレッドシートの取り込み（4列）
- `data/harowaka_coder_jobs_enriched.csv` … 調査結果を8列追加した最終版（12列）
- `research/findings.jsonl` … 会社ごとの調査結果（1行1社）

## 追加した列
| 列 | 内容 |
|---|---|
| 事業内容・強み領域 | その会社が実際に何で食べているか |
| 数字で語れる強み | 創業年・従業員数・実績件数・取引社数・受賞など、原文にあった数字 |
| 理念・想い（抽出） | 理念/ビジョン/代表あいさつ/社名の由来から、想いが出ている記述 |
| 社風・働き方 | 募集条件（リモート可否・稼働時間・経験年数）と組織の姿勢 |
| 他社との差別化ポイント | 本リスト130社を母集団として、その会社だけの特徴 |
| 営業フック（刺さる切り口） | その会社に営業するときに効く具体的な切り口 |
| 出典 | 根拠にした公開ページ |
| 情報確度 | 高（公式サイトの記述が確認できた）/ 中（第三者DB中心）/ 低（情報が乏しい・同名企業の混同リスクあり） |

## 調査方法と制約（重要）
このセッションはネットワークポリシーにより **企業サイトへの直接アクセスが遮断されている**ため、
各社サイトをブラウザで開いて原文を読む方法は取れなかった。
代わりに **Web検索（公式サイトの会社概要・理念・代表挨拶ページを含む）** から情報を収集している。

そのため:
- 「理念・想い」列の文は **公式ページの記述に基づく要約または引用** であり、一字一句の原文引用を保証していない。
  営業文面にカギカッコ付きで引用する場合は、出典URLで原文を必ず確認すること。
- 情報確度「低」の8社は、公開情報が乏しいか同名企業との混同リスクがある。営業前に直接サイト確認が必要。

## 情報確度の内訳
- 高: 91社 / 中: 31社 / 低: 8社
