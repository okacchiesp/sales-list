## 調査方法と制約（重要）
このリモート環境はネットワークポリシーにより **企業サイトへの直接アクセスが遮断されている**
（curl / WebFetch とも 403）。したがって「各社サイトの全ページを閲覧」は実施できていない。
代替として **Web検索（公式サイトの採用ページ・実績ページ・会社概要の内容を含む検索結果）＋
第三者DB（Web幹事・比較ビズ・優良WEB・転職媒体・PR TIMES等）＋公式SNS** から収集した。

そのため：
- 募集要項の細かい条件（単価・稼働時間・必須スキルの全文）は**未確認**の会社が多い。
  営業前に必ず該当ページを直接開いて確認すること。
- 「情報確度」列の意味
  - 高：公式の採用/パートナー募集ページや公式SNSの記述が検索結果で確認できた
  - 中：第三者DB中心。方向性は合っているが細部は要確認
  - 低：公開情報が乏しい、または同名企業・類似ドメインとの混同リスクあり
